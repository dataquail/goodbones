---
title: Defining a campaign
description: The fields of a campaign and a full example.
---

A campaign is an entry under the top-level `campaigns` key, keyed by its id. This page lists
every field; the next pages cover each part.

## Example

Billing moving to domain-driven design, one bounded context at a time:

```yaml
campaigns:
  billing-ddd:
    why: Untangle billing into bounded contexts behind ports.
    owner: "@your-org/billing"
    scope: src/**
    legacy: src/services/** # unclaimed files that count as legacy
    perimeter:
      marker: "**/context.ts" # each context.ts marks one sector
    onTouch: ratchet

    phases:
      - id: domain
        intent: a domain module with no I/O
        objectives: [no-io-in-domain]
      - id: repository
        intent: a repository with a migration
        objectives: [has-migration]
      - id: backfilled
        intent: legacy rows copied and verified
        attested: true # no detector sees this; `campaigns attest` leaves it
      - id: cutover
        intent: the flag and the legacy write path are removed
        objectives: [no-legacy-write]
      - id: aggregates # open: no objectives yet, so it must be last
        intent: Model refunds inside the billing aggregate, or split them out.

    objectives:
      no-io-in-domain:
        intent: A domain module that reads the file system cannot be tested without one.
        holdout: declaration
        match:
          all:
            - path: { file: "/domain/" }
            - members: { subject: calls, name: "readFileSync" }
        probes: { fires: [{ path: src/billing/domain/a.ts, source: "readFileSync('x')" }] }
      has-migration: # the sector is the holdout until one file matches
        intent: A context without a migration has no table of its own to cut over to.
        holdout: sector
        sector: { has: { path: { file: "/migrations/.*\\.ts$" } } }
      no-legacy-write:
        intent: A write to the legacy path after cutover is a row the new store never sees.
        holdout: match
        match: { syntax: { pattern: "legacyBilling.write($$$)" } }
        probes: { fires: [{ path: src/billing/a.ts, source: "legacyBilling.write(x)" }] }
```

## Fields

Only `objectives` is required.

| Field        | Meaning                                                                                                                                                                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`      | A display name.                                                                                                                                                                                                                    |
| `why`        | The rationale for the refactor. Printed by `explain` and `conformance`. Each objective states its own [`intent`](/goodbones/campaigns/manifest/objectives/).                                                                       |
| `how`        | What to do at a holdout. Every finding carries it unless the objective sets its own.                                                                                                                                               |
| `owner`      | Who runs the campaign. Printed in the status table.                                                                                                                                                                                |
| `scope`      | Globs of the files it sees (default: every file), as [`graph`](/goodbones/architecture-rules/manifest/graph/) takes. `{ path, extensions }` also widens the walk. See [Sectors](/goodbones/campaigns/manifest/sectors/#the-scope). |
| `legacy`     | Which unclaimed files count as legacy. Default: all of them. See [Sectors](/goodbones/campaigns/manifest/sectors/).                                                                                                                |
| `shared`     | The files every sector shares: on no phase, in no sector. See [Sectors](/goodbones/campaigns/manifest/sectors/#the-sharedFiles).                                                                                                   |
| `perimeter`  | How a sector is recognized. See [Sectors](/goodbones/campaigns/manifest/sectors/).                                                                                                                                                 |
| `onTouch`    | What a touched sector owes: `advise`, `ratchet` or `paydown`. See [The nudge](/goodbones/campaigns/running/nudge/).                                                                                                                |
| `onAhead`    | What a diff owes that pays down a phase the sector has not reached: `advise` (default), `ratchet` or `ignore`. See [`onAhead`](/goodbones/campaigns/running/nudge/#onahead).                                                       |
| `phases`     | The ordered steps. See [Phases](/goodbones/campaigns/manifest/phases/).                                                                                                                                                            |
| `endState`   | Shorthand for the last phase, as a sector-relative node tree. See [Phases](/goodbones/campaigns/manifest/phases/).                                                                                                                 |
| `objectives` | The detectors, keyed by id. See [Objectives](/goodbones/campaigns/manifest/objectives/).                                                                                                                                           |
| `staleAfter` | How long without progress before the report calls it stalled, such as `14d` or `12h`. Default: never.                                                                                                                              |
| `onComplete` | `keep` (default; stays as a guard against recurrence) or `remove` (`check` fails until you delete it).                                                                                                                             |

[Writing a plan](/goodbones/campaigns/manifest/planning/) collects what moving a real sector
through a campaign taught about choosing objectives and ordering phases.

The top-level `ledger` key sets where ledgers are written, relative to the manifest. Default:
`.architecture-campaigns`.

Findings have kind `campaign` and rule name `campaign/<campaign>/<objective>`. They are judged
against the objective's [ledger](/goodbones/campaigns/running/ledger/), never the baseline.
