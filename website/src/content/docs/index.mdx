## Architecture Rules

Describe each folder's imports, exports and files in one manifest, and lint every change against it.

<CardGrid>
  <Card title="One manifest" icon="document">
    Rules sit at the folder they govern, so the file reads like a directory listing. [Read the
    overview →](/goodbones/architecture-rules/manifest/)
  </Card>
  <Card title="Real resolution" icon="approve-check">
    Rules match the file an import resolves to, through your `tsconfig` paths and workspace links.
    [How resolution works →](/goodbones/architecture-rules/enforcement/resolution/)
  </Card>
  <Card title="Tight by default" icon="setting">
    A folder admits only the files and imports you list. Loosening a rule is always explicit. [Read
    about inheritance →](/goodbones/architecture-rules/manifest/inheritance/)
  </Card>
  <Card title="Every rule proves itself" icon="warning">
    The plugin refuses to load if a rule can no longer match anything. [How probes work
    →](/goodbones/architecture-rules/enforcement/probes/)
  </Card>
  <Card title="Adopt gradually" icon="seti:config">
    Record today's violations in a baseline; the build fails if the count grows. [Adopting a policy
    →](/goodbones/architecture-rules/enforcement/adoption/)
  </Card>
  <Card title="Editor and CLI" icon="seti:typescript">
    Get feedback in the editor through oxlint, or check the whole repository with the CLI. [CLI
    reference →](/goodbones/architecture-rules/enforcement/cli/)
  </Card>
</CardGrid>

## Campaigns

Track a multi-step refactor in the same manifest, and see how far each part of the code has moved.

<CardGrid>
  <Card title="A refactor you can measure" icon="list-format">
    Each objective lists every place its pattern still occurs. The list only shrinks. [Read the
    introduction →](/goodbones/campaigns/getting-started/introduction/)
  </Card>
  <Card title="A plan written as you learn" icon="random">
    Define the phases you know now and leave the rest open. [How phases work
    →](/goodbones/campaigns/manifest/phases/)
  </Card>
  <Card title="A nudge on every change" icon="rocket">
    Anyone who touches the code is told what would move it to the next phase. [Read about the nudge
    →](/goodbones/campaigns/running/nudge/)
  </Card>
</CardGrid>
